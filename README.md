# stellakamikaze/tap

Homebrew tap for [Cornetta](https://cornetta.stellakamikaze.org/en/), a free, open-source call recorder for Mac.

```sh
brew install --cask stellakamikaze/tap/cornetta
```

Cornetta is not notarized: on first launch open System Settings › Privacy & Security and click «Open Anyway». The app updates itself after that. Source: [stellakamikaze/cornetta](https://github.com/stellakamikaze/cornetta).
